# Bino-Windows-Tools
Il Tool di Bino per sistemare tanti problemi di Windows
Questo script è stato creato con l'aiuto della AI, nel tempo sono state integrate diverse funzioni, inizialmente semplici e minime per poi diventare più complesse e utili al lavoro dell'IT che necessita di funzioni di diagnostica rapida e verifica OS Windows client e server, in particolare alcune funzioni permettono di risolvere problemi di lentezza del sistema operativo e ripristino dei componenti delle versioni Windows 10 e 11, è stato integrato da poco anche AD-Tools che include comandi di lettura Active Directory per generare dei report di vario tipo riguardanti utenti e gruppi. Nell'ultima release siamo arrivati a ben 136 comandi totali così divisi:

AD-TOOLS: 22
